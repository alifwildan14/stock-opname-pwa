📦 Stock Opname v7

Aplikasi stock opname untuk HP. Cari part, hitung stok saat ini, simpan — datanya langsung masuk database Supabase dan bisa di-export ke file Excel (.xlsx).

Yang baru di v7

  • Data master diganti total: 636 part baru (10 Nov 2026) — sebelumnya 4.008 part lama.
  • Kolom baru Article No. di Data Master, detail part, Riwayat Revisi, pencarian, dan export Excel.
  • Data baru tidak punya Part Name — kolom nama tampil kosong.
  • Supabase: jalankan SQL ganti master di README.txt agar data baru tampil saat online.

Yang baru di v6

  • Tampilan baru: sidebar gelap, kartu statistik berikon, tombol +/− untuk hitung stok, tabel berubah jadi kartu di HP.
  • Sidebar dengan menu Home, Data Master, Stock, Riwayat Revisi, Komplain, dan About.
  • Form opname lebih simpel: hanya Stok Saat Ini + Waktu Input (tanggal, jam, menit).
  • Riwayat Revisi: lihat opname per tanggal dan lacak perubahan satu part dari waktu ke waktu.
  • Komplain: laporkan part bermasalah beserta status tindak lanjutnya.
  • Mode gelap untuk kerja di gudang yang redup.

Data

Master part & hasil opname: Supabase (636 part, dengan Article No.). Data baru tidak punya Part Name, jadi kolom nama tampil kosong. Bila tidak ada internet, aplikasi tetap jalan (mode offline) dan hasil opname terkirim otomatis begitu online lagi.

Data & Penyimpanan

Tombol di atas hanya menghapus data di HP ini — data di Supabase tidak ikut terhapus.
